
# Contributing to DataFlippers

Thank you for your interest in helping us build educational tools! To ensure a smooth experience for everyone, please follow these guidelines.

## 1. How to Contribute
We welcome contributions from developers of all skill levels, especially those interested in education and data science.

* **Claim an Issue:** Before writing code, please browse our [Issue Tracker](https://github.com/cbennington852/DataFlippers/issues) and comment on an existing issue or open a new one to discuss your proposed changes. This prevents duplicate work.
* **Fork and Branch:** Fork the repository and create a descriptive branch name (e.g., `feature/add-new-block` or `fix/logic-error`).
* **Coding Standards:** Please follow the [Language, e.g., PEP 8 for Python] style guide. Ensure your code is well-commented, as this is an educational project meant to be read by learners.
* **Pull Request (PR) Process:**
    1.  Ensure all existing tests pass.
    2.  Update the documentation if you are adding a new feature.
    3.  Submit your PR with a clear description of the changes and link it to the relevant issue.
    4.  A maintainer will review your code and may suggest changes before merging.

## 2. Reporting Issues
If you find a bug or have a suggestion for a new feature, please use our GitHub Issues page.

* **Check for Duplicates:** Search existing issues to see if your problem has already been reported.
* **Be Specific:** Include the version of the software you are using, your operating system, and the steps to reproduce the bug.
* **Screenshots/Logs:** For UI-related bugs or crashes, attaching a screenshot or a copy of the error log is extremely helpful.
* **Feature Requests:** We love ideas! When suggesting a feature, please describe the "User Story" (e.g., *"As a teacher, I want to be able to..."*).

## 3. Seeking Support
If you are having trouble using the module or need clarification on the documentation, please use the following channels:

* **Discussion Forum:** For general questions, "How-to" help, and architectural discussions, please open a [github issue](https://github.com/cbennington852/DataFlippers/issues).
* **Documentation:** Always check our [docs](https://cbennington852.github.io/DataFlippers/) first, as most setup questions are answered there.
