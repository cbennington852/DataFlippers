A classifier is a type of AI model that looks at the features of an input and assigns it to a specific category. It learns by studying examples that are already labeled, eventually figuring out the "rules" that separate one group from another. 

A classic example is a "spam filter," which acts as a classifier by deciding if an incoming message belongs in your Inbox or the Junk folder.
Example: 
- Inputs : 
	- Email title
	- Email body
	- Email address
- Output : 
	- Is Spam? (yes or no)

|                                      | **Classification**                                                                                                                                                                |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Description**                      | Takes in any combination of input data, and outputs a prediction in the form of a class.<br><br>Example:<br>- Input: ``bill_length_mm = 39.1`` <br>- Output: `Island = Torgenson` |
| **Prediction data type**             | Categorical                                                                                                                                                                       |
| **Ways to assess model performance** | - Accuracy                                                                                                                                                                        |
