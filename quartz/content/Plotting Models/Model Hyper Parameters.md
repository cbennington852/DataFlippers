
Each model has it's own hyperparamters! These are a set of values that we can use to **fine tune** a model. 

### How to
1. Move any (model , scalar, or validator) into a pipeline. 
2. Click on the draggable model. 
![[Pasted image 20260219142600.png]]
3. Alter the parameters. 
4. Parameters have a "tooltip" this can be seen by hovering over the name or the question mark.
