Preproccessors are functions that transform and change the data before they are run through the AI model. These can help with various task and benefits. 
- These are not required to plot a pipeline in DataScratch. 

## Scalars
 A Scaler is a tool used to resize your numerical data so that all features are on a similar scale. If you have one column for "Age" (0–100) and another for "Annual Income" (0–200,000), a machine learning model might mistakenly think Income is "more important" just because the numbers are bigger. 

## Transformers
A transformer applies a mathematical function to input data to change it into an entirely new set of data. These can be used to clean, reduce, expand, or generate feature representations from data
